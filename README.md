# Shopper 🛍️

**Shopper** is a mobile-first AI autonomous shopping assistant designed for the PayPal AI Competition. It acts as an intelligent companion to help users discover the best deals, track live promos, and evaluate products using advanced AI.

---

## ✨ Key Features

* **Custom Sidebar Navigation**: Clean, mobile-responsive layout featuring intuitive icons for seamless switching between sections.
* **Proactive AI Notifications**: Real-time alerts keeping you updated on price drops and shopping trends.
* **Integrated Tabs**:
  * **Agent Search**: Input what you are looking for and let the AI search the web and evaluate the best options.
  * **Recommendations**: Curated product suggestions tailored to your budget.
  * **Promos**: Live web promos and discounts fetched for local shoppers.
  * **News**: Tech and shopping insights, safety tips, and market updates.

---

## 🛠️ Tech Stack

* **Backend**: Python (Flask)
* **AI & Search**: Groq AI (Llama 3.3 reasoning) & Tavily API
* **Frontend**: HTML5, CSS3, and JavaScript (Custom Coffee Brown & Golden Yellow / Clean Green aesthetic)
